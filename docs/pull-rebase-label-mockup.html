확인창 버튼 이름 — Pull and Rebase

주황 Pull 확인창의 파란 버튼만 받아 얹기 → Pull and Rebase로 바꾼다. 누르면 도는 일이 pull --rebase라는 것을 버튼 자리에서 바로 읽는다. 캡슐 툴팁과 설명 산문의 ‘받아 얹기’는 그대로 둔다 — 버튼은 명령 이름, 산문은 그 명령이 무슨 일인지를 말하는 자리다.

취소Pull and Rebase

제목은 손대지 않는다. 제목의 (Pull --rebase)는 실제 git 옵션 표기이고 버튼은 사람이 읽는 동사라, 둘이 겹쳐 보여도 말하는 층이 다르다.

2 · 옆 창(주황 Push)은 어떻게 할까 고르는 자리

같은 주황 상태의 Push 확인창에는 받아 얹고 Push 버튼이 있다. 이 창을 그대로 두면 두 확인창의 버튼 언어가 갈린다. 아래 둘 중에 골라 주세요.

취소받아 얹고 Push

‘가’는 제목 괄호에 이미 적혀 있는 Pull Rebase and Push를 버튼이 그대로 받는다 — 두 창의 버튼이 같은 언어로 선다.

규칙

  • 바뀌는 것은 확인창 버튼 글자뿐이다. 도는 명령, 판정, 캡슐, 툴팁, 흐름은 그대로다.
  • 캡슐 툴팁과 문서의 ‘받아 얹기’는 남는다 — 무슨 일이 벌어지는지 설명하는 자리다.
  • 초록 Pull은 확인창 없이 즉시 실행이므로 이 시안과 무관하다.
  • 흐름 계약 테스트의 버튼 글자도 함께 옮긴다(test/upstream_sync_flow_contract_test.dart).
