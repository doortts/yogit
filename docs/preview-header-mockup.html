덧붙임 — 결정에 걸린 것

툴팁 지연없음 — 올리면 바로. 나갈 때도 바로 사라진다.
메시지 로딩부모 메시지는 필요할 때 git log -1로 읽고 캐시한다(Full Diff가 쓰는 캐시 그대로). 읽는 동안 툴팁은 제목·날짜만 먼저 보여준다.
부모 제목 출처부모가 타임라인에 이미 있으면 그 제목을 즉시 쓰고, 없으면(범위 밖) 메시지 캐시로 채운다.
복사 대상표시도 복사도 7자리(2280d58).
텍스트 선택헤더 줄 전체가 드래그로 선택·복사된다 — 복사 아이콘은 손 안 대고 해시만 집을 때의 지름길.
Full Diff 진입⌘D · 상단 툴바 버튼 · 파일 클릭 — 헤더 버튼만 사라진다.
