# 타임라인 행 간격 축소 설계

## 목표

타임라인의 커밋 표현 간격을 위아래 `1px`씩 줄인다. 현재 `32px`인 공통
행 높이를 `30px`로 바꿔 같은 화면에 더 많은 커밋을 표시한다.

## 구현

`TimelineScreen.rowHeight`만 `32.0`에서 `30.0`으로 변경한다. 목록의
`itemExtent`, 그래프 셀, 레일과 노드의 중심, 선택 행, 키보드 이동 및
스크롤 위치 계산은 이미 이 상수를 사용하므로 별도 보정값을 추가하지
않는다.

날짜 구분 행도 같은 상수를 사용해 `30px`로 줄인다. 커밋 행만 별도 높이로
나누면 고정 높이 목록과 스크롤 계산을 바꿔야 하므로 범위에서 제외한다.

## 검증

- 타임라인 공통 행 높이가 `30px`인지 확인한다.
- 목록의 `itemExtent`와 실제 커밋·날짜 행 높이가 공통 행 높이를 따르는지
  기존 테스트로 확인한다.
- 그래프 선, 노드, 선택 행과 스크롤 이동 테스트가 새 높이에서도 통과하는지
  확인한다.
