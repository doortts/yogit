# Full Diff 단축키 배지 위치 수정 설계

## 목표

Full Diff 화면에서 `⌘` 키를 누를 때 나타나는 단축키 배지가 버튼 아래쪽의 다른 아이콘이나 콘텐츠와 겹치지 않게 한다. 기존 배지 모양과 글자 크기, 버튼 위치, 도구막대 높이는 유지한다.

## 원인

`FullDiffShortcutHint`는 배지를 레이아웃 밖의 오버레이에 그린다. 현재 배지는 버튼 하단에서 4픽셀 떨어진 위치부터 시작한다. 배지 전체가 버튼 밖으로 내려오지만 도구막대는 그 공간을 확보하지 않기 때문에, 다음 도구막대나 본문이 가까우면 배지가 다른 아이콘 위에 놓인다.

## 승인된 디자인

비교 시안의 A안을 적용한다.

- 배지는 버튼 아래 중앙에 정렬한다.
- 배지 시작 위치를 현재보다 8픽셀 위로 옮긴다.
- 결과적으로 배지 윗부분이 버튼 하단 테두리에 4픽셀 겹친다.
- 배지의 글자 크기, 안쪽 여백, 색상, 테두리와 둥근 모서리는 바꾸지 않는다.
- 배지를 표시할 때도 버튼과 도구막대의 위치 및 높이는 바뀌지 않는다.
- 모든 Full Diff 단축키 배지에 같은 위치 규칙을 적용한다.

## 구현 범위

공통 컴포넌트인 `FullDiffShortcutHint`의 세로 오프셋만 변경한다. 각 버튼이나 도구막대에서 위치를 따로 조절하지 않는다. 단축키 처리, 배지의 표시 조건과 접근성 정보는 건드리지 않는다.

## 검증

- 배지가 버튼 하단보다 4픽셀 위에서 시작하는지 위젯 테스트로 확인한다.
- `⌘` 키를 눌러도 버튼 위치가 변하지 않는지 기존 테스트로 확인한다.
- 단축키 배지가 모두 표시되고 키를 떼면 사라지는지 확인한다.
- Full Diff 검수 화면을 다시 캡처해 배지가 다른 아이콘이나 본문과 겹치지 않는지 확인한다.
- 전체 테스트를 실행해 다른 Full Diff 기능에 영향이 없는지 확인한다.

## 완료 조건

단축키 배지가 승인된 A안처럼 버튼 하단에 붙어 보이고, 모든 Full Diff 화면 크기에서 다른 아이콘이나 본문을 가리지 않는다.
