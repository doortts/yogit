# Merge·Rebase 미리보기 시각 검토

## 검토 조건

- 기준 페이지와 실제 앱을 1280×720, 100% 배율로 캡처했다.
- Merge 성공, Rebase 성공, Merge 충돌, Rebase 충돌 네 상태를 각각 비교했다.
- 기존 타임라인 레일은 HTML 시안과 픽셀 단위로 비교하지 않았다. `GraphRow`와 `CommitGraphPainter`의 기존 선, 곡률, 연결 규칙이 유지되는지만 확인했다.
- 미리보기에서 추가된 가상 레일, 가상 병합 연결선, Rebase 대응선은 시안과 엄격히 비교했다.

## 상태별 결과

### Merge 성공

- `Merge 미리보기`와 녹색 체크 아이콘, 성공 요약 카드, 실제 적용 버튼을 확인했다.
- 보라색 `VM` 노드와 두 부모에서 이어지는 1px 점선 연결을 확인했다.
- 최종 파일 목록과 Unified/Side-by-side 전환을 확인했다.

### Rebase 성공

- `Rebase 미리보기`와 녹색 체크 아이콘, 보라색 결과 카드, 실제 적용 버튼을 확인했다.
- 가상 커밋이 기준 브랜치 HEAD 위에 배치되고 1px 점선으로 이어지는지 확인했다.
- 원본과 재작성 커밋을 잇는 어두운 직교 대응선, 화살표, 같은 색 테두리를 확인했다.
- 최종 파일 목록과 Unified/Side-by-side 전환을 확인했다.

### Merge 충돌

- `Merge 충돌` 요약, 임시 공간 안내, 붉은 충돌 상태를 확인했다.
- 가상 병합 노드까지 이어지는 1px 점선과 충돌 파일 목록을 확인했다.
- 기준 브랜치와 대상 브랜치 내용을 보여주는 diff 및 해결 선택지를 확인했다.

### Rebase 충돌

- `Rebase 충돌` 요약, 진행 순서, 임시 공간 안내를 확인했다.
- 기준 브랜치 HEAD 위의 빈 도착점과 1px 점선, 현재 충돌 커밋의 붉은 행 강조를 확인했다.
- 적용 완료 행은 보라색, 대기 행은 황색으로 구분되는지 확인했다.
- 기준 브랜치와 대상 브랜치 내용을 보여주는 diff 및 해결 선택지를 확인했다.

## 결론

시안의 문구, 상태 색, 보라색 가상 요소, 추가된 1px 점선, 대응선, 행 강조, Unified/Side-by-side 전환과 일치한다. 예외로 정한 기존 타임라인 레일도 기존 앱의 연결 규칙을 유지한다.

필수 시각 요소 차이: 0

비교에서 제외한 차이는 시안 웹 페이지의 상태 전환용 바깥 틀, 테스트 저장소의 커밋·파일 내용, 테마에 따라 달라지는 기존 타임라인 레일 색이다.
