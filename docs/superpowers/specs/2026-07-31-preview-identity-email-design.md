# 미리보기 신원 이메일 표시 설계

## 목표

커밋 미리보기의 Author와 Committer 정보에 각 신원의 이메일을 표시한다.

## 표시 방식

이름 아래의 역할 줄에 이메일을 함께 표시한다.

```text
Suwon Chae
Author · suwon@example.com
2026-07-31 11:13:36
```

- Author와 Committer가 다르면 두 카드에 각자의 이메일을 표시한다.
- 두 신원이 같으면 현재처럼 Author 카드 하나만 표시한다.
- 이메일을 앞뒤로 다듬은 결과가 비어 있으면 역할만 표시한다.
- 긴 이메일은 한 줄에서 말줄임표로 처리한다.
- 이메일은 역할과 같은 보조 색상과 크기를 사용한다.
- 작업 트리 항목은 커밋 신원이 없으므로 기존 문구를 유지한다.

## 선택한 이유

별도 이메일 줄은 카드 높이를 늘리고 툴팁만 사용하는 방식은 정보를 바로 확인할 수 없다. 기존 역할 줄에 붙이면 현재 높이와 정보 위계를 유지하면서 이메일을 항상 볼 수 있다.

## 검증

- Author와 Committer가 다를 때 각 카드에 올바른 이메일이 표시되는지 확인한다.
- 같은 신원은 카드 하나와 이메일 하나만 표시되는지 확인한다.
- 빈 이메일은 구분자 없이 역할만 표시되는지 확인한다.
