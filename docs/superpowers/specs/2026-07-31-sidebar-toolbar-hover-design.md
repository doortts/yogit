# 사이드바와 상단 메뉴 호버 디자인

## 목표

마우스를 올렸을 때 브랜치·태그 이름과 상단 메뉴가 클릭 가능한 요소임을
즉시 알 수 있게 한다. 미리보기 창은 앱 전체 폭의 75%까지 넓힐 수 있게
한다. 미리보기 본문은 커밋 정보부터 diff까지 한 흐름으로 스크롤한다.

## 확정된 동작

### 브랜치와 태그

- 브랜치·태그 호버 영역은 이름 앞의 브랜치·태그 아이콘부터 행 오른쪽
  끝까지다. 폴더 들여쓰기와 펼침 아이콘 영역은 포함하지 않는다.
- 호버 배경은 모서리가 둥글지 않은 직사각형이다.
- 호버 영역 왼쪽에는 굴곡 없는 2픽셀 직선이 나타난다.
- 직선은 해당 브랜치 선의 색을 사용한다.
- 이름과 보조 문구는 기존 색 체계를 유지하면서 한 단계 밝아진다.
- 폴더 행과 현재 선택 동작은 바꾸지 않는다.

### 상단 메뉴

- `Enter` 키캡은 현재 호버 동작을 유지한다.
- 미리보기 위치 버튼은 호버 시 중립 배경과 글자가 밝아진다.
- 설정 버튼은 중립 배경이 나타나고 톱니바퀴가 18도 회전한다.
- `Full Diff`는 호버 시 기본 `#2EA043`보다 밝은 `#3FB950`으로 바뀐다.
- 버튼 크기, 간격, 클릭 영역과 선택 상태는 바꾸지 않는다.

### 미리보기 창

- 가로 배치일 때 최대 폭은 앱 창 전체 폭의 75%다.
- 창 크기가 바뀌면 최대 폭도 즉시 다시 계산한다.
- 최소 폭 240과 초기 폭 288은 유지한다.
- 저장된 폭에는 고정된 픽셀 상한을 적용하지 않는다.
- 저장된 값이 현재 창의 75%보다 크면 화면에서는 동적 상한까지만 표시한다.
- 아래 배치의 높이 범위는 바꾸지 않는다.
- 상단 제목과 `Full Diff` 버튼은 고정한다.
- 커밋 정보, 작성자 정보, 파일 목록과 diff는 하나의 세로 스크롤 흐름으로
  묶는다.
- diff 위에서 스크롤해도 위쪽 정보와 파일 목록이 함께 움직인다.
- 파일 이동 단축키는 선택한 파일 행을 다시 화면 안으로 가져온다.
- Merge/Rebase 충돌 단계가 바뀌거나 해결이 끝나면 새 상태를 바로 볼 수
  있도록 미리보기 본문을 맨 위로 되돌린다.

## 구현 경계

기존 `TimelineScreen`, 설정 역직렬화와 상단 버튼을 그대로 사용한다.
새 패키지나 별도 테마 설정은 추가하지 않는다. 호버 상태는 해당 행이나
버튼만 다시 그리도록 작은 상태 위젯에 둔다.

## 검증

- 마우스 포인터를 브랜치·태그 아이콘부터 이름 영역에 옮겨 직사각형 배경과
  2픽셀 직선을 확인한다.
- 위치 버튼, 설정 버튼과 `Full Diff`의 호버 상태를 각각 확인한다.
- 서로 다른 창 너비에서 미리보기가 창 전체 폭의 75%에서 멈추는지 확인한다.
- diff 위에서 스크롤했을 때 커밋 정보와 파일 목록이 함께 이동하는지
  확인한다.
- 전체 위젯 테스트, 정적 검사와 macOS 디버그 빌드를 실행한다.
