# 크롬 정리 네 가지 — 로고 중앙, 콘솔 이사, ⌘, 설정, 미리보기 컨트롤 이사

2026-08-14 · 시안 파일: `docs/chrome-four-moves-mockup.html`

## 1. 워드마크를 창 중앙에

지금 워드마크는 브랜치 선택기와 우측 버튼 무리 **사이에 남은 공간**의 가운데에 선다
([timeline.dart:2195](../lib/timeline.dart#L2195)의 `Spacer(flex: 5) · 2 · 2 · 5`).
좌우 무리의 폭이 다르니 남은 공간의 중앙은 창의 중앙이 아니다 — 스샷처럼 오른쪽으로
치우친다.

**규칙** (macOS 타이틀바 관례):

- 워드마크는 **창 기준 중앙**. 툴바 전체를 `Stack`으로 감싸고 워드마크를
  `Align(center)` + `IgnorePointer`로 띄운다. 기존 Row는 그대로 두고 Spacer 사이의
  워드마크만 뺀다 — 드래그 영역은 지금처럼 남는다.
- **공간이 모자라면 감춘다.** 창 중앙 ± (워드마크 절반 + 24px 여유)에 좌측 무리(선택기
  끝)나 우측 무리(미리보기 컨트롤 시작)가 들어오면 워드마크를 접는다. 지금도 두 단계
  (26px → 20px → 0)로 줄고 있으니 같은 사다리를 창-중앙 기준으로 다시 잰다:
  중앙에 26px이 안 서면 20px, 그것도 안 서면 없음.
- 계산에 쓰는 값은 렌더 후 측정이 아니라 **레이아웃 제약으로 유도**한다. 툴바
  LayoutBuilder가 전체 폭을 이미 알고, 좌측 무리 폭은 선택기 폭 계산에서 이미 나온다
  ([timeline_chrome.dart:38](../lib/timeline_chrome.dart#L38)). 우측 무리는 이사(4번) 뒤
  고정 폭에 가까워진다.

## 2. 콘솔 버튼 → 상태바, 프로필 칩 왼쪽

지금 콘솔 버튼(`toolbar-console`, `Icons.terminal`)은 툴바 우측 설정 기어 옆이다.
로그를 보는 일은 상태 확인이지 문서 작업이 아니니 상태바가 맞는 자리다.

**규칙**:

- 상태바 우측 끝의 프로필 칩 **바로 왼쪽**으로 옮긴다
  ([timeline_chrome.dart:462](../lib/timeline_chrome.dart#L462) 옆).
- 아이콘은 `Icons.terminal`(창틀 그림) 대신 **`>_` 글리프**를 모노 폰트로 그린다 —
  상태바의 10–11px 텍스트 크기에 맞고, 창틀 없는 프롬프트가 더 간결하다.
- 상태 색은 지금 규칙 그대로: 콘솔 열림 = text, 명령 실행 중 = behindOrange, 평소 =
  muted. ⌘` 단축키와 툴팁도 그대로 온다.
- 툴바에서는 버튼이 사라진다. 우측 무리는 `모니터링 · 미리보기 토글 · 설정`만 남는다.

## 3. 설정: ⌘, + 마지막 페이지 기억

- **⌘,** — macOS 설정 단축키 관례. 타임라인 키 핸들러(⌘` 옆,
  [timeline.dart:1518](../lib/timeline.dart#L1518))에 `LogicalKeyboardKey.comma`를
  추가하고 `widget.onOpenSettings`를 부른다. 기어 버튼은 그대로 둔다.
- **마지막 섹션 기억** — 지금은 열 때마다 `_SettingsSection.gitIntegrations` 고정
  ([settings.dart:1177](../lib/settings.dart#L1177)). `AppSettings`에
  `settingsSection` 문자열을 저장하고, 섹션 탭을 누를 때마다 기록, 열 때 복원한다.
  저장값이 모르는 이름이면(섹션이 사라진 미래) 기본값으로.

## 4. 미리보기 배치 버튼 → 미리보기 pane 상단

지금 툴바 우측의 `미리보기 [좌측|우측|하단]` 세그먼트 + 여닫기 토글 중, **배치 세그먼트가
미리보기 pane의 머리줄로** 들어간다. 배치를 고르는 일은 미리보기의 일이니 그 판에
붙는 게 맞다.

**규칙**:

- 미리보기 헤더(36px, [timeline_preview_pane.dart:236](../lib/timeline_preview_pane.dart#L236))
  우측 끝에 **아이콘 세그먼트**로 선다: 텍스트(좌측/우측/하단) 대신 pane 위치 글리프
  3개 (▮□ □▮ □▯ 꼴). 헤더에는 커밋 라인이 이미 있어서 텍스트 세그먼트는 좁다.
  현재 배치가 눌린 상태로 표시된다.
- 옮겨간 세그먼트 옆에 **닫기(×)** 를 둔다 — 판 안에서 판을 닫는 자리.
- **툴바에는 여닫기 토글 하나만 남는다.** 미리보기가 닫혀 있으면 pane도 헤더도 없으니,
  다시 여는 문은 툴바에 있어야 한다. Enter 단축키도 그대로.
- `미리보기` 캡션 텍스트는 은퇴한다 — 토글 버튼의 툴팁이 이미 말한다.

## 하지 않는 것

- 설정을 모달/시트로 바꾸는 것. 지금 route 그대로.
- 콘솔 버튼의 실행-중 카운트 배지. 점 색이 이미 말한다.
- 워드마크 페이드 애니메이션. 접히는 건 창 크기 조절 중뿐이라 애니메이션이 설 무대가 없다.
