## 지적 사항

### P2 — diff 안내 글꼴과 가로 너비 계산에 이전 크기가 남아 있었습니다

설계는 diff의 빈 상태와 오류 안내를 10px로 줄이도록 정했지만 다음
경로에는 이전 값이 남아 있었습니다.

- 표시 불가 패널과 공통 로딩·오류 안내: 14px
- Hunk·Inline·Split의 방어용 빈 상태: 14px
- patch 갱신 실패 안내: 12px
- 줄바꿈을 끈 Hunk의 가로 너비 계산: 실제 10px 글자를 14px로 계산

사용자에게 보이는 안내의 밀도가 설계와 달랐고, 긴 Hunk에서는 글자
오른쪽에 불필요한 가로 스크롤 영역이 생겼습니다.

실패 테스트로 먼저 확인했습니다.

- 표시 불가 패널 여섯 상태와 History 상세 로딩: 예상 10px, 실제 14px
- Hunk·Inline·Split 빈 상태: 예상 10px, 실제 14px
- patch 갱신 실패 안내: 예상 10px, 실제 12px
- 긴 Hunk의 계산 너비: 예상 6,534px, 실제 9,110px
- 15번 시각 캡처: 4,235픽셀, 0.47% 차이

안내 글꼴을 모두 10px로 맞추고 Hunk 너비도 10px 글꼴로 계산하도록
고쳤습니다. 같은 테스트가 모두 통과했고, 다시 검토한 15번 이미지는
경로, 통계, 속성, 사유와 옵션 순서를 유지하면서 글자가 잘리지
않았습니다.

남은 P0, P1, P2, P3 지적 사항은 없습니다.
