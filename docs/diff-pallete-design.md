# GitHub Dark diff 색상 설계

## 목표

Yogit의 diff 창을 GitHub Primer의 `dark` 기본 테마와 같은 색상 체계로 바꾼다. Unified와 Side-by-side가 같은 팔레트를 사용하며 레이아웃, 줄 높이, 선택 동작, diff 계산 방식은 바꾸지 않는다.

사용자가 승인한 시안처럼 diff 배경부터 추가·삭제 줄, 줄 번호 영역, 단어 단위 강조, hunk 헤더, 비어 있는 반대편 칸까지 함께 맞춘다. 추가·삭제 줄만 바꾸고 기존 회색 배경을 유지하는 부분 적용은 제외한다.

## 기준

색상은 2026-07-31에 확인한 GitHub Primer Primitives의 `dark` 테마를 기준으로 한다.

- [`diffBlob` 컴포넌트 토큰](https://github.com/primer/primitives/blob/3f51f80ee9510974032917c9b8ac9586656c88bc/src/tokens/component/diffBlob.json5)
- [`dark` 기본 색상](https://github.com/primer/primitives/blob/3f51f80ee9510974032917c9b8ac9586656c88bc/src/tokens/base/color/dark/dark.json5)

Primer가 지정한 반투명 줄 색은 `#0D1117` 위에 합성한 최종 색으로 저장한다. 현재 `FullDiffCodeRow`는 줄 바탕 아래에 줄 번호 영역을 겹쳐 그리므로 원본 투명도를 그대로 쓰면 색이 두 번 합성된다. 최종 색을 쓰면 위젯 구조를 바꾸지 않고 GitHub 웹 화면과 같은 결과가 나온다. 단어 강조만 줄 바탕 위에 실제로 겹쳐져야 하므로 Primer의 투명도를 유지한다.

| 영역 | Primer 토큰 | 앱에서 쓰는 색상 |
|---|---|---|
| diff 바탕 | `#0D1117` | `#0D1117` |
| 헤더·빈 칸 바탕 | `#151B23` | `#151B23` |
| 기본 테두리 | `#3D444D` | `#3D444D` |
| 기본 글자 | `#F0F6FC` | `#F0F6FC` |
| 보조 글자 | `#9198A1` | `#9198A1` |
| 추가 줄 | `rgba(46, 160, 67, 0.15)` | `#12261E` |
| 추가 줄 번호 | `rgba(63, 185, 80, 0.30)` | `#1C4328` |
| 추가 단어 | `rgba(46, 160, 67, 0.40)` | 같은 반투명 색 |
| 삭제 줄 | `rgba(248, 81, 73, 0.10)` | `#25171C` |
| 삭제 줄 번호 | `rgba(248, 81, 73, 0.30)` | `#542426` |
| 삭제 단어 | `rgba(248, 81, 73, 0.40)` | 같은 반투명 색 |
| hunk 줄 | `rgba(56, 139, 253, 0.10)` | `#111D2E` |
| 빈 칸 빗금 | `#212830` | `#212830` |
| 미니맵 추가·삭제 표시 | `#3FB950` / `#F85149` | 같은 색 |

## 적용 방식

`full_diff_theme.dart`를 팔레트의 단일 기준으로 유지한다. 기존 상수의 값을 바꾸고 추가와 삭제가 함께 쓰던 `fullDiffWordChange`를 추가용과 삭제용 상수로 나눈다. 별도의 테마 계층이나 설정 화면은 만들지 않는다.

`FullDiffCodeRow`는 `DiffLineKind`에 따라 줄 바탕, 줄 번호 바탕, 기호, 단어 강조 색상을 한 번에 고른다. Unified와 Side-by-side는 이미 이 위젯을 함께 사용하므로 두 화면에 같은 결과가 적용된다.

`FullDiffHunkHeader`와 `HatchedDiffCell`은 같은 중앙 팔레트의 hunk·빈 칸 색상을 사용한다. 빗금의 모양과 간격은 그대로 두고 색상만 바꾼다.

## 동작과 예외

색상만 바뀌므로 데이터 흐름과 오류 처리는 달라지지 않는다. 줄 선택, 현재 변경 표시, 텍스트 선택, 구문 강조는 기존 동작을 유지한다. 구문 강조가 있는 글자는 기존 구문 색상을 쓰되 줄과 단어의 바탕색만 GitHub Dark 팔레트를 따른다.

## 검증

- 팔레트 상수가 승인된 값과 일치하는지 검사한다.
- 추가와 삭제 줄의 단어 강조가 서로 다른 색을 쓰는지 위젯 테스트로 확인한다.
- Unified와 Side-by-side에서 줄·줄 번호·hunk·빈 칸 색상이 같은 중앙 팔레트를 쓰는지 기존 테스트를 보강한다.
- 관련 Flutter 테스트와 `flutter analyze`를 실행한다.
- 기존 전체 diff 시각 테스트를 실행해 레이아웃이나 줄 높이가 바뀌지 않았는지 확인한다.

## 제외 범위

- 사용자가 색상을 직접 고르는 설정
- GitHub의 다른 테마인 Dark dimmed, 고대비, 색각 보정 모드
- diff 계산, 줄 정렬, 구문 분석 변경
- 앱 전체 색상 체계 변경
