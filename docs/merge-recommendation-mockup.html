통합 방법 추천 — 판정 규칙과 칩 시안

브랜치 diff 요약 바 오른쪽 끝의 추천 칩은 지금도 있다. 바뀌는 것은 무엇을 근거로 무엇을 고르는가뿐이고, 칩과 근거 패널의 생김새는 그대로 쓴다. 추천은 충돌 없이 끝나는 방법이 있을 때만 낸다 — 전부 충돌이면 아무것도 밀지 않는다.

1. 판정 규칙 개정 2

위에서부터 걸리는 첫 줄이 답이다. 어느 쪽도 못 고르면 칩을 아예 그리지 않는다 — 틀린 추천은 없는 추천보다 나쁘다.

공유의 재정의 — push 여부가 아니라 남의 흔적

지금 엔진은 push된 적 있음 = 공유 = 재배치 금지로 읽는다. PR 흐름에서는 과하다 — PR을 올리려면 push가 전제라서, 이 규칙대로면 PR 브랜치는 전부 Merge로 몰린다. 재배치가 실제로 다치게 하는 것은 남의 커밋뿐이다.

신호읽기재배치
옮길 커밋(base..compare)에 남이 쓴 커밋이 섞임진짜 공유 브랜치 — dev·main처럼 여럿이 쌓는 곳제외
원격 tip이 내 tip도 그 조상도 아님남의 브랜치인지 내 재배치 흔적인지 알 수 없음추천 자체 없음
push됐지만 옮길 커밋이 전부 내 것PR용 개인 브랜치허용 — force-push 필요를 근거에 명시
push된 적 없음로컬 전용허용

"내 것"은 옮길 커밋의 author 이메일이 전부 user.email과 같다는 뜻이다. git log --format=%ae base..compare 호출 1회로 안다. 웹 UI로 만든 커밋처럼 주소가 섞여 보이면 안전한 쪽(Merge)으로 넘어간다.

판정

#조건판정
1merge base 없음 · fast-forward로 끝남 · 가져올 커밋 없음 · 원격 tip 관계 불명추천 없음
2rebase가 깨끗하고 재배치가 허용됨 — 기본값, PR 표준 흐름Rebase 후 Merge
3위와 같으나 기준 브랜치 관례가 선형 (머지 커밋 비율 < 0.15)Rebase
4merge만 깨끗Merge
5그 밖 — 전부 충돌 포함추천 없음

이전 엔진의 관례 문턱(머지 커밋 비율 ≥ 0.4)과 표본 문턱(50개 중 10개)은 2번에서 뺐다 — 재배치 후 merge가 기본이고, 관례는 3번(선형 예외)에서만 본다. 기준이 원격 브랜치(origin/dev)면 yogit 몫은 재배치까지고 merge는 PR이 한다 — 판정은 같고 근거 문구가 그걸 말한다. 충돌 없이 끝나는 방법이 하나도 없으면 어느 쪽도 추천하지 않는다 — 충돌 규모 비교로 순위를 매기는 것은 억지 추천이다.

2. 칩 — 상태별

Rebase 후 MergePR 흐름 — 기준은 원격 dev, 작업 브랜치는 push된 내 브랜치
Rebase 미리보기 ✓ 가상 커밋 6개 점선 이동 경로 실제 브랜치 변경 없음 추천: Rebase 후 MergePR 표준 흐름 feat/#31 → origin/dev
왜 Rebase 후 Merge인가
·옮길 커밋 6개가 전부 내 커밋이라 재배치해도 남의 작업을 지우지 않습니다
·Rebase 미리보기 6개 커밋 전부 충돌 없이 재생됐습니다
·원격 feat/#31이 이미 있어 push는 force-with-lease로 — merge는 PR이 합니다

기준이 로컬 브랜치면 같은 판정에 merge 적용까지 yogit이 한다. push된 적 없는 브랜치면 첫 줄이 "로컬 전용이라 히스토리를 다시 써도 아무도 안 다칩니다"로, 셋째 줄은 빠진다.

Mergerebase는 충돌, merge는 깨끗
Merge 미리보기 ✓ 가상 커밋 1 충돌 없음 추천: Merge재배치는 충돌에서 멈춤 main ← feature/pull-menu
왜 Merge인가
·Rebase 시뮬레이션은 충돌 파일 3개에서 멈추지만 Merge는 충돌이 없습니다
Rebase관례가 선형인 저장소
Rebase 미리보기 ✓ 가상 커밋 4개 점선 이동 경로 실제 브랜치 변경 없음 추천: Rebase커밋 4개 · 선형 유지 feature/row-chip → main
왜 Rebase인가
·브랜치가 로컬 전용이라 히스토리를 다시 써도 아무도 안 다칩니다
·Rebase 미리보기 4개 커밋 전부 충돌 없이 재생됐습니다
·최근 main 커밋 50개 중 머지 커밋은 3개뿐이라 선형 히스토리가 관례입니다
추천 없음칩 자리를 비워 둔다
Merge 충돌 충돌 7개 임시 공간 사용 중 main ← feat/old-work

전부 충돌인 비교가 이 자리다 — 원격 tip이 내 tip과 무관하게 갈라진 브랜치(공유 판정 불명)도 같은 자리로 온다. 자리를 비워 두지, "판단 보류" 같은 문구를 넣지 않는다. 말할 게 없다는 것 자체가 화면에서 조용해야 한다.
