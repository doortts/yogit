제안 — 워드마크는 Stack 오버레이로 창 중앙에. 콘솔 버튼과 배치 세그먼트가 이사(2·4번)해서 우측도 한산해졌다. 좁아져 좌우 무리가 중앙 ±(반폭+24px)에 들어오면 26→20→숨김 사다리로 접힌다.

명령 실행 중 — 지금 점 색 규칙 그대로 글리프가 주황이 된다. 콘솔이 열려 있으면 text 색.

3. 설정 — ⌘ , + 마지막 페이지 기억

⌘ , →
Appearance
커밋 프로필 ← 지난번에 보던 곳
Git integrations
커밋 메시지 템플릿

기어 버튼·경로는 그대로, 단축키만 는다. 마지막 섹션은 설정 파일에 저장 — 모르는 이름이면 기본값으로 연다.

4. 미리보기 배치 — 툴바 세그먼트 → pane 머리줄

텍스트(좌측/우측/하단) 대신 위치 글리프. 현재 배치가 눌려 있다. 닫기(×)도 판 안으로.

SC

제안 — 배치 고르기는 미리보기의 일이라 그 판 머리에 붙는다. 커밋 라인이 좁아지면 글리프 세그먼트가 우선 남고 부모 제목이 먼저 줄어든다.

닫혀 있을 때 여는 문은 툴바에 남는 여닫기 토글(◧)과 Enter. 배치 세그먼트는 판과 함께 사라지니, 다시 열면 마지막 배치로 선다 — 지금 동작 그대로.

은퇴: 툴바의 `미리보기` 캡션 텍스트. 토글 툴팁이 이미 말한다.
