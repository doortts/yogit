동작 정의

1
diff 영역 전환. Unstaged는 작업 트리 ↔ 인덱스, Staged는 인덱스 ↔ HEAD를 비교한다. 전환하면 헝크 버튼도 Stage ↔ Unstage로 바뀐다. 커밋 패널에서 파일을 클릭하면 그 파일이 속한 섹션으로 자동 전환된다.
2
파일 단위 Stage. 지금 보는 파일을 통째로 인덱스에 올린다. Staged 영역을 보는 중이면 같은 자리에 Unstage File이 온다.
3
Hunk 단위. Stage Hunk는 헝크 하나만 인덱스에 올리고, Staged 쪽에서는 Unstage Hunk가 된다. Discard Hunk는 작업 트리에서 되돌리며 확인창을 먼저 띄운다.
4
두 섹션. Unstaged(위) / Staged(아래, 커밋 버튼 바로 위). ▾로 접히고, 우측 텍스트 버튼은 Stage All · Unstage All.
5
Unstaged 행 hover. ＋ Stage File, ↺ Discard(확인창). 추적되지 않는 파일은 untracked 칩이 붙고, Discard가 파일 삭제라는 점을 확인창에 명시한다.
6
Staged 행 hover. − Unstage File 하나만. 인덱스만 되돌리므로 작업 트리 내용은 그대로 남는다.
7
제목 글자 수. 50자 카운터, 넘으면 주황으로 바뀌지만 막지는 않는다. 본문은 별도 입력.
8
커밋 버튼. Staged가 비었거나 제목이 비면 비활성. --amend 체크 시 HEAD 메시지를 채워 넣고 라벨이 커밋 수정으로 바뀐다. 이미 푸시된 커밋이면 경고를 함께 보여준다.
9
키보드. Space로 선택한 파일을 Stage ↔ Unstage 토글, ⌘↵ 커밋, ↑↓ 파일 이동, Esc로 diff 닫기.
