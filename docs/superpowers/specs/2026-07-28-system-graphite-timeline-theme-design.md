# System Graphite 기본 화면 테마 설계

## 목표

기본 타임라인 화면에서 짙은 남색으로 느껴지는 배경을 걷어내고 Apple
플랫폼에 자연스럽게 어울리는 어두운 회색 계열로 바꾼다. 사용자가 고른
`System Graphite` 시안을 기준으로 화면의 깊이는 중립 회색 명도 차이로
구분하고 색상은 선택 상태와 Git 정보처럼 뜻이 있는 곳에만 쓴다.

레이아웃, 간격, 글꼴 크기, 기능, 키보드 조작은 바꾸지 않는다.

## Apple 디자인 원칙

- 배경과 앞쪽 표면은 서로 다른 명도의 중립색으로 나눠 깊이를 드러낸다.
- 작은 글자는 배경과 최소 4.5:1 이상의 대비를 갖게 한다.
- 시스템 블루는 선택 상태와 조작 가능한 요소에만 제한해서 쓴다.
- 경계선은 얇고 차분하게 유지한다. 경계선만으로 구역을 나누기보다 표면
  명도 차이를 함께 쓴다.
- 브랜치, 태그, 파일 상태처럼 의미가 있는 기존 색은 보존한다.

참고:

- [Apple Human Interface Guidelines: Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)
- [Apple Human Interface Guidelines: Color](https://developer.apple.com/design/human-interface-guidelines/color)
- [Apple Human Interface Guidelines: Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)

## 범위

### 포함

- 기본 화면 바탕과 타임라인 목록
- 상단 도구 막대와 하단 상태 막대
- 왼쪽 브랜치·원격·태그 사이드바
- 열 머리글, 검색 입력창, 키 표시, 중립 상태 칩
- 기본 화면에 붙어 열리는 미리보기 패널
- 기본 화면에서 사용하는 저장소·기준 브랜치 메뉴

### 제외

- Full Diff 화면의 전용 색상
- 설정 화면의 전용 색상
- 구문 강조, 추가·삭제, 브랜치 그래프 색의 의미 체계
- 레이아웃, 크기, 애니메이션, 탐색 동작 변경
- 밝은 테마나 사용자가 고르는 테마 기능
- 실제 Liquid Glass나 흐림 효과 추가

## 색상 체계

| 역할 | 현재 | 변경 |
| --- | --- | --- |
| 기본 바탕 | `#15171E` | `#1C1C1E` |
| 도구·상태 막대 | `#1D2029` | `#242426` |
| 사이드바·열 머리글 | `#1A1D25` | `#202022` |
| 입력창·떠 있는 중립 표면 | `#252936` | `#2C2C2E` |
| 경계선 | `#343946` | `#38383A` |
| 기본 글자 | `#E8EAF2` | `#F2F2F7` |
| 보조 글자·아이콘 | `#8D94A8` | `#AEAEB2` |
| 중립 칩 | `#263246` | `#2C2C2E` |
| 선택 행 | `#1F4D8F` | `#234D72` |
| 시스템 블루 강조 | 여러 파란색 | `#0A84FF` |

선택 행의 `#234D72`는 시스템 블루를 그대로 채우는 대신 중립 바탕과 섞은
색이다. 선택 상태는 분명하지만 화면 전체가 다시 남색으로 보이지 않게
채도를 낮춘다. 기본 화면에서 Material이 그리는 조작 요소의 주 강조색은
`#0A84FF`를 쓴다. 날짜, 해시, 그래프 선처럼 Git 정보를 구분하는 기존
색에는 이를 일괄 적용하지 않는다.

승인된 조합의 대비는 기본 글자와 바탕이 15.25:1, 보조 글자와 바탕이
7.69:1, 기본 글자와 선택 행이 7.92:1이다.

## 화면 요소별 적용

### 창과 도구 막대

창 바탕은 `#1C1C1E`, 도구 막대와 상태 막대는 `#242426`을 쓴다. 저장소와
기준 브랜치 조작부는 현재 구조를 유지한다. 눌림 영역이나 키 표시는
`#2C2C2E`로 올려서 조작 가능한 요소임을 명도로 구분한다.

macOS 창 제어 버튼과 Yogit 글자색은 브랜드 요소이므로 그대로 둔다.

### 사이드바

사이드바는 `#202022`로 바탕보다 한 단계 밝게 만든다. 섹션 아이콘과 개수,
접기 화살표는 `#AEAEB2`를 쓴다. 브랜치 끝점의 그래프 색과 태그 상태색은
정보를 나타내므로 바꾸지 않는다.

선택한 브랜치 행은 타임라인 선택 행과 같은 색상 체계를 쓴다. 선택되지
않은 행에는 별도의 푸른 배경을 넣지 않는다.

### 타임라인

열 머리글은 사이드바와 같은 `#202022`를 써서 기능 영역으로 묶는다. 커밋
목록은 `#1C1C1E`를 유지한다. 날짜 구분, 해시, 브랜치 선, 파일 상태색은
뜻이 있는 색이므로 현재 값을 유지한다.

선택 행은 `#234D72`로 채우고 기본 글자는 `#F2F2F7`로 표시한다. 선택 행
외곽이나 별도의 강한 그림자는 추가하지 않는다.

### 미리보기

미리보기 패널도 기본 화면에 속하므로 바탕, 제목 영역, 경계선, 파일 선택
행을 같은 색상 체계로 바꾼다. diff의 추가·삭제 색과 파일 상태 글자색은
유지한다. 미리보기에서 Full Diff로 전환하면 Full Diff 전용 테마를 그대로
쓴다.

## 구현 경계

새로운 테마 설정 기능이나 추상화 계층은 만들지 않는다. 기본 화면에 이미
있는 색상 상수와 Material 테마의 기본 표면색을 필요한 만큼만 바꾼다.
Full Diff의 `full_diff_theme.dart`와 설정 화면의 전용 색상 값은 건드리지
않는다.

공통 Material 색을 바꿔야 하는 메뉴나 팝업은 기본 화면에서 새 회색을
쓰게 한다. Full Diff와 설정 화면에 의도하지 않은 색 변화가 없는지 화면
테스트로 확인한다.

## 상태와 오류 처리

색상만 바꾸므로 데이터 흐름과 오류 처리는 달라지지 않는다. 로딩, 비활성,
오류 상태는 기존 문구와 아이콘을 유지하되 새 바탕에서 읽을 수 있도록
기본 글자와 보조 글자 색을 적용한다.

## 검증

- 주요 색상 상수가 승인된 값과 일치하는지 위젯 테스트로 확인한다.
- 기본 화면, 사이드바 선택, 타임라인 선택, 미리보기 선택 상태를 확인한다.
- 저장소·기준 브랜치 메뉴가 새 표면색과 읽기 쉬운 글자색을 쓰는지
  확인한다.
- Full Diff와 설정 화면의 전용 팔레트가 바뀌지 않았는지 관련 테스트로
  확인한다.
- `flutter analyze`와 전체 `flutter test`를 실행한다.
- 가능하면 기본 화면을 캡처해서 승인된 `System Graphite` 시안과 나란히
  비교한다.

## 완료 조건

1. 기본 화면의 넓은 영역에서 남색 기운이 사라지고 중립 회색 계층이
   보인다.
2. 선택한 행과 조작 가능한 요소는 시스템 블루로 분명하게 구분된다.
3. Git 상태와 브랜치 그래프의 의미 색은 유지된다.
4. Full Diff와 설정 화면은 기존 전용 테마를 유지한다.
5. 기존 조작과 테스트가 그대로 통과한다.
