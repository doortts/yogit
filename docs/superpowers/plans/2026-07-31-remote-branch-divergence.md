# 원격 브랜치 커밋 차이 표시 구현 계획

**목표:** 같은 이름의 로컬 브랜치가 있으면 원격 브랜치 행에 로컬 대비 `+N −M`을 표시하고 앱이 열려 있는 동안 실제 원격 정보를 주기적으로 확인한다.

**구조:** 기존 `RepoRefs` 로딩과 3분 주기 `fetchRemote` 흐름을 그대로 확장한다. 원격별로 한 번만 fetch한 뒤 같은 이름의 로컬·원격 브랜치를 로컬 Git 데이터로 비교한다. 작업 트리와 브랜치는 바꾸지 않는다.

**기술:** Flutter, Dart, Git CLI, 기존 위젯·저장소 테스트

### 1. 차이 계산

- `test/git_test.dart`에 upstream 설정과 무관하게 같은 이름의 로컬·원격 브랜치 차이를 계산하는 실패 테스트 추가
- `RepoRefs`에 원격 브랜치 기준 차이 결과 추가
- 기존 `rev-list --left-right --count` 계산 재사용

### 2. 원격 행 표시

- `test/app_test.dart`에 원격 행의 `+N −M`, 동일한 경우 숨김, 대응 로컬 브랜치가 없는 경우 숨김 테스트 추가
- `lib/timeline.dart`의 기존 원격 행에만 작은 차이 표시 추가

### 3. 주기적 원격 확인

- 선택 브랜치의 upstream만 조회하던 테스트를 같은 이름의 로컬 브랜치가 있는 원격 목록 기준으로 변경
- 시작 시와 3분마다 원격별로 한 번 fetch
- 앱이 비활성 상태이거나 조회 중이거나 충돌 해결 중이면 기존처럼 건너뜀
- 실패하면 마지막 성공 값 유지

### 4. 검증과 병합

- 관련 테스트, `flutter analyze`, 전체 `flutter test` 실행
- 커밋 후 `main`에 병합
- 병합된 `main`에서 전체 테스트 재실행
