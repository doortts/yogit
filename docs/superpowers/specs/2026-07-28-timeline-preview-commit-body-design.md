# 타임라인 미리보기 커밋 본문 표시 설계

## 배경

타임라인 목록은 빠른 조회를 위해 커밋 제목만 읽는다. 오른쪽 미리보기도 이 제목을 그대로 사용해, 본문이 있는 커밋을 선택해도 제목 아래 내용이 보이지 않는다.

## 목표

- 제목 아래에 커밋 본문을 원래 줄바꿈대로 표시한다.
- 본문이 없는 커밋과 작업 트리 미리보기는 현재 모습을 유지한다.
- 타임라인 목록 조회 비용은 늘리지 않는다.

## 설계

커밋을 선택하면 미리보기에서만 `GitRepository.loadCommitMessage`로 전체 메시지를 지연 조회한다. 기존 `FullDiffCommitMessageCache.shared`를 재사용해 저장소 경로와 SHA가 같은 메시지를 중복 조회하지 않는다.

기존 제목은 즉시 표시한다. 전체 메시지를 읽은 뒤 첫 줄을 제외한 나머지가 있으면 제목 아래에 본문을 추가한다. 본문은 앞뒤의 빈 줄만 정리하고 내부 줄바꿈은 유지한다. 조회가 실패하거나 본문이 비어 있으면 제목만 남긴다.

## 테스트

본문이 포함된 전체 메시지를 반환하는 가짜 저장소로 미리보기를 연 뒤 제목과 여러 줄 본문이 모두 표시되는지 확인하는 위젯 테스트를 추가한다. 기존 미리보기 테스트와 전체 Flutter 테스트, 정적 검사를 실행하고 macOS Release 앱에서 실제 본문이 있는 커밋으로 확인한다.

## 완료 기준

- 커밋 제목과 본문이 미리보기에 함께 표시된다.
- 본문의 줄바꿈이 유지된다.
- 본문이 없거나 조회가 실패해도 기존 제목은 계속 보인다.
- 타임라인 목록과 작업 트리 미리보기 동작은 바뀌지 않는다.
