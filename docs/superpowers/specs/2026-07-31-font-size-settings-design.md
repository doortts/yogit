# 글자 크기 설정 설계

## 목표

사용자가 앱의 글자 크기를 용도별로 조절할 수 있게 한다. 설정은 세 영역으로 제한하고 기존 화면의 글자 크기 위계는 유지한다.

- Interface
- Lists & Content
- Code & Diff

각 값은 80%부터 140%까지 5%p 단위로 조절한다. 기본값은 100%다.

## 설정 화면

Appearance 화면에 `Font size` 영역을 추가한다.

각 영역의 설정 행에는 다음 요소를 둔다.

- 영역 이름과 적용 범위
- 현재 비율
- 80%~140% 슬라이더
- 5%p씩 줄이거나 늘리는 `−`, `+` 버튼

세 영역 위에는 `All areas` 조절 행을 둔다. `−`, `+` 버튼을 누르면 세 값을 각각 5%p씩 줄이거나 늘린다. 값의 차이는 유지하며 경계에 도달한 값만 80% 또는 140%에 머문다. 세 값이 같으면 하나의 비율을 표시하고 다르면 최솟값과 최댓값을 범위로 표시한다.

전체 조절 행에는 `⌘−`, `⌘+` 단축키 안내를 표시한다.

## 단축키

앱 화면에서 다음 단축키를 지원한다.

- `⌘−`: 세 영역을 각각 5%p 줄인다.
- `⌘+`: 세 영역을 각각 5%p 늘린다.

`⌘+`는 macOS 키 입력에 맞춰 `⌘=`와 `⇧⌘=`를 모두 처리한다. 단축키는 설정 화면을 포함한 앱 전체에서 동작하며 변경값은 즉시 저장한다.

별도의 전체 배율은 저장하지 않는다. 단축키와 `All areas` 버튼이 세 영역 값을 직접 바꾸므로 배율이 중첩되지 않는다.

## 적용 범위

### Interface

- 상단 바와 도구 모음
- 버튼, 메뉴, 탭, 입력창
- 설정 화면과 툴팁
- 상태 표시줄과 일반 안내 문구

### Lists & Content

- 브랜치와 태그 목록
- 커밋 목록, 열 헤더와 각 셀
- 파일과 히스토리 목록
- 커밋 미리보기 본문과 메타데이터

목록 안의 해시처럼 고정폭 글꼴을 쓰는 텍스트도 해당 목록의 배율을 따른다.

### Code & Diff

- Diff 원문
- 줄 번호
- hunk 헤더
- Blame 코드 영역

글꼴 종류는 바꾸지 않고 크기만 조절한다.

## 화면 적용 방식

기존 `TextStyle`에 지정된 크기는 유지한다. 세 영역의 위젯 트리에 `MediaQuery`의 `TextScaler.linear`를 적용해 현재 크기 비율을 보존한다.

앱 전체에는 Interface 배율을 적용하고 Lists & Content와 Code & Diff 하위 트리에서 해당 배율로 덮어쓴다. 이 방식으로 직접 지정된 기존 글자 크기를 전부 공통 스타일로 바꾸지 않아도 된다.

글자가 들어 있는 고정 높이 행과 버튼은 해당 배율이 100%를 넘을 때 함께 커진다. 100% 아래에서는 현재 최소 높이를 유지해 클릭 영역이 지나치게 작아지지 않게 한다.

## 저장 형식

`AppSettings`에 다음 정수 값을 저장한다.

- `interfaceFontScalePercent`
- `contentFontScalePercent`
- `codeFontScalePercent`

저장값이 없거나 숫자가 아니면 100%를 사용한다. 숫자라면 80%~140% 범위로 제한한 뒤 가장 가까운 5%p 단위로 맞춘다.

기존 설정 파일에는 새 값이 없으므로 모두 100%로 읽혀 현재 화면과 같은 크기를 유지한다.

## 오류와 경계 처리

- 80%에서 감소 동작은 값을 바꾸지 않는다.
- 140%에서 증가 동작은 값을 바꾸지 않는다.
- 전체 조절 중 일부 값만 경계에 도달하면 나머지 값만 계속 바뀐다.
- 슬라이더와 버튼은 경계에 도달한 방향을 비활성화한다.
- 잘못 저장된 값 때문에 설정을 읽지 못하는 일은 없어야 한다.

## 검증

- 세 설정값의 기본값, 저장과 복원, 잘못된 값 보정을 단위 테스트한다.
- 각 슬라이더와 `−`, `+` 버튼이 5%p 단위로 값을 바꾸는지 위젯 테스트한다.
- `All areas` 버튼과 `⌘−`, `⌘+`가 세 값을 함께 바꾸고 저장하는지 검증한다.
- 세 화면 영역에 서로 다른 배율이 적용되는지 검증한다.
- 140%에서 주요 목록 행, 버튼과 Diff 화면에 오버플로가 없는지 위젯 테스트한다.

## 제외 범위

- 글꼴 종류 변경
- 개별 위젯마다 별도의 크기 설정
- 전체 배율과 영역별 배율을 곱하는 방식
- `⌘0` 초기화 단축키
- macOS 이외 운영체제용 단축키
