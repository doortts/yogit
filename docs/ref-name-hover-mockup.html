잘린 브랜치·태그 이름에 hover하면 전체 이름

BRANCH / TAG 칸은 이름을 앞에서부터 줄인다. 꼬리가 남으니 대개는 알아볼 수 있지만 …ne-palette-assignments처럼 앞이 통째로 사라지면 어느 브랜치인지 못 읽는다. 잘린 이름에만 hover로 전체를 보여준다. 칸 밖으로 넘어가도 된다.

A안 — 옆으로 열리는 카드 이미 있는 부품

사이드바가 잘린 이름에 쓰는 SideTooltip을 그대로 타임라인 칩에 붙인다. 행과 같은 줄 오른쪽에 열려서 아래 행을 가리지 않고, 오른쪽 끝에 자리가 없으면 왼쪽으로 비킨다. 앱 안에서 이미 한 번 배운 동작이라 새로 익힐 것이 없다.

B안 — 칩이 제자리에서 펴진다 새로 만들어야 함

칩이 자기 자리에서 전체 이름 너비만큼 자라 GRAPH 칸 위로 넘어간다. 브랜치 색과 테두리를 그대로 들고 가서, 읽는 사람이 보던 물건이 그대로 커진 것으로 읽힌다. 대신 그래프 레일을 잠깐 덮는다.

계약

1이름이 칸 안에 다 들어가면 아무것도 안 뜬다. 이미 보이는 것을 덮는 건 방해다.
2잘린 칩에 마우스가 올라가면 전체 이름이 뜬다. 칸 밖으로 넘어가도 된다.
3흐린 줄 이름 칩도 같은 규칙을 따른다.
4마우스가 벗어나면 곧바로 사라진다. 클릭이나 선택은 관계없다.
5한 행에 칩이 여러 개면 마우스가 올라간 그 칩의 이름만 뜬다.
6떠 있는 동안 마우스 입력을 가로채지 않는다 — 아래 행을 계속 누를 수 있다.
