# 기준 브랜치 색상 설정 설계

## 목표

설정 화면의 `Main line (fixed)`를 `Base branch`로 바꾸고 사용자가 색상을
수정할 수 있게 한다. 선택한 기준 브랜치는 일반 타임라인과 브랜치 비교
화면에서 이 색상을 사용한다.

## 설정

- `AppSettings`에 `baseBranchColor`를 별도 값으로 저장한다.
- 기본값은 현재 고정 색상인 `#5CB270`이다.
- 저장값이 올바른 6자리 16진수 색상이 아니면 기본값을 사용한다.
- 기존 `laneColors`는 기준 브랜치가 아닌 나머지 레일의 팔레트로 유지한다.
- 색상 초기화는 기준 브랜치 색상과 기존 레일 팔레트를 모두 기본값으로
  되돌린다.

기존 설정 파일에는 `baseBranchColor`가 없으므로 별도 마이그레이션 없이
기본값을 적용한다.

## 화면

`Timeline colors`의 첫 행을 다른 색상 행과 같은 견본과 16진수 입력란으로
표시한다. 이름은 `Base branch`로 바꾸고 `(fixed)` 표시는 없앤다.

입력 중 완성되지 않은 값은 지금처럼 저장하지 않는다. 올바른 값이
입력되면 견본과 타임라인에 바로 반영한다.

## 색상 적용 흐름

앱은 설정을 읽거나 변경할 때 기준 브랜치 색상과 기존 레일 팔레트를
`AvatarService`에 전달한다. 타임라인은 현재 선택한 기준 브랜치 끝을
`preferredTip`으로 넘겨 0번 브랜치 레일에 배치한다. 0번 브랜치의 레일,
곡선, 점, 아바타, 브랜치 표시는 모두 설정된 기준 브랜치 색상을 사용한다.

기존 레이아웃은 기준 브랜치에 0번 레인을 예약하지만 브랜치 ID는 커밋이
나타난 순서대로 붙인다. 더 최신인 다른 브랜치가 있으면 기준 브랜치가
0번이 아닌 ID를 받을 수 있다. `preferredTip`이 있으면 브랜치 ID 0도 함께
예약해 레인과 색상 역할을 일치시킨다.

기준 브랜치를 바꾸면 `_rebuildGraph()` 흐름이 새 기준 브랜치를 0번
브랜치로 다시 배치한다. 별도 상태나 브랜치별 색상 표는 추가하지 않는다.
브랜치 비교 화면도 기준 브랜치를 0번 브랜치로 배치하는 기존 규칙을
그대로 사용한다.

## 검증

- 기준 브랜치 색상이 설정 JSON에 저장되고 다시 읽힌다.
- 값이 없거나 잘못되면 `#5CB270`을 사용한다.
- 설정 화면에서 기준 브랜치 색상을 수정하고 초기화할 수 있다.
- 저장한 기준 브랜치 색상이 일반 타임라인의 0번 브랜치에 적용된다.
- 기준 브랜치를 바꾸면 새 기준 브랜치 레일이 같은 색상을 사용한다.
- 브랜치 비교 화면의 기준 브랜치 레일도 같은 색상을 사용한다.
