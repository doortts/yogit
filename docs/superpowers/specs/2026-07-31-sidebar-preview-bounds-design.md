# 왼쪽 패널과 하단 미리보기 크기 설계

## 목표

- 왼쪽 패널은 150픽셀보다 좁아지지 않게 한다.
- 하단 미리보기는 현재 창 높이에 맞춰 타임라인의 컬럼 헤더 바로 아래까지 늘릴 수 있게 한다.
- 사용자가 지정한 미리보기 높이는 앱을 다시 실행해도 유지한다.

## 설계

왼쪽 패널은 드래그할 때 적용하는 최소값과 설정을 불러올 때 적용하는 최소값을 모두 150픽셀로 맞춘다. 이미 저장된 값이 150픽셀보다 작아도 다음 실행부터 150픽셀로 보정한다.

하단 미리보기의 최대 높이는 고정값을 사용하지 않는다. 작업 영역의 전체 높이에서 컬럼 헤더 29픽셀을 뺀 값을 최대 높이로 사용한다. 브랜치 비교 화면에서는 컬럼 헤더 위의 요약 영역 52픽셀도 남긴다. 따라서 미리보기를 최대로 늘려도 `BRANCH / TAG`를 포함한 컬럼 헤더는 계속 보인다.

설정 파일에는 사용자가 지정한 높이를 그대로 저장한다. 화면에 표시할 때 현재 창에서 허용하는 최대 높이로 제한하므로 큰 모니터에서 저장한 값을 작은 창에서 불러와도 레이아웃이 넘치지 않는다.

## 검증

- 왼쪽 패널을 충분히 왼쪽으로 끌었을 때 150픽셀에서 멈추고 그 값이 저장되는지 확인한다.
- 저장된 150픽셀 미만의 값이 150픽셀로 보정되는지 확인한다.
- 900픽셀 높이의 창에서 하단 미리보기를 위로 끌었을 때 기존 480픽셀을 넘어 컬럼 헤더 바로 아래까지 커지는지 확인한다.
- 큰 미리보기 높이를 설정 파일에 저장했다가 다시 읽어도 값이 유지되는지 확인한다.
- 브랜치 비교 화면에서는 요약 영역과 컬럼 헤더를 모두 남기는지 확인한다.
