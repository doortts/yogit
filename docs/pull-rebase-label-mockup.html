동기화 표기 — Rebase

upstream 동기화의 우리말 ‘얹다’를 걷어내고 Rebase로 통일한다. 확인창 버튼은 도는 명령 그대로 Pull and Rebase · Pull Rebase and Push, 제목과 툴팁은 그 명령을 한국어 문장 안에서 부른다 — Rebase로 받을까요, Rebase한 뒤 Push, Rebase한 커밋은 해시가 달라집니다.

제목의 (Pull --rebase)는 git 옵션 표기 그대로고, 버튼은 눌렀을 때 도는 일의 이름이다. 둘 다 같은 낱말을 쓰므로 읽는 사람이 옮겨 읽을 것이 없다.

3 · 캡슐 툴팁 같은 낱말로

  • 주황 Pull — 빨리감기는 불가, Rebase로 받습니다 — 충돌 없음
  • 주황 Push — 8개를 Rebase한 뒤 충돌 없이 Push할 수 있습니다
  • 빨강 — 빨리감기는 불가, Rebase하면 lib/a.dart 외 1개가 충돌합니다 — 눌러서 해결

규칙

  • 바뀌는 것은 글자뿐이다. 도는 명령, 판정, 흐름, 위젯 구조는 그대로다.
  • rebase는 옮기지 않는다 — 버튼에서도 문장 안에서도 Rebase다.
  • 초록 Pull은 확인창 없이 즉시 실행이라 이 표기와 무관하다.
  • 계약 테스트는 버튼을 Key로 잡고 제목은 글자로 잡으므로, 제목이 바뀌면 테스트도 함께 옮긴다.
